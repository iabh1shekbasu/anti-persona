# Reference implementation

`final_method_reference.py` restates the whole final method in one file of plain PyTorch, with comments pointing
at the lines of the research code that produced the paper's images. It was tested equal to that code on the CPU
(largest difference 0 on the real CLIP encoder for the four loss terms and the total; bit-identical 30-step loops and
final PNGs with a stand-in encoder, on one Yo'LLaVA dataset photo and one MMPB dataset photo). sha256 of this file:
`9ac4fb4add860186c164915f08acacf4dc56bc08958a913f8cf7ad28f1a2cbd9`.

The line references in its comments (`A:`, `P:`, `E:`, ...) point to that internal research code, which is not part
of this release. The package `anti_persona/` splits this file into modules without changing the arithmetic;
`tests/test_equivalence.py` checks that bit for bit. Do not edit this file.
